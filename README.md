# 🏪 مهر استور | سیستم مدیریت فروشگاه

نرم‌افزار کامل و فارسی مدیریت فروشگاه برای ویندوز — صندوق فروش، انبار، مشتریان، گزارش‌ها، هزینه‌ها و پشتیبان‌گیری خودکار، همه در یک برنامه.

## ⬇️ دانلود و نصب

به صفحه [**Releases**](https://github.com/ahmaddaneshvar1992-oss/MehrStore/releases/latest) بروید و فایل‌ها را دانلود کنید:

| فایل | کاربرد |
|---|---|
| `MehrStore-Setup.exe` | نصب‌کننده اصلی (حدود ۳۸ مگابایت) |
| `MehrStore-Setup.zip` | همان نصب‌کننده داخل زیپ — اگر مرورگر فایل exe را بلاک کرد |
| `MehrStore-Setup.exe.part1` تا `part5` | نسخه تقسیم‌شده برای اینترنت ضعیف |
| `ساخت فایل نصبی.bat` | ادغام خودکار ۵ بخش و ساخت فایل نصبی — در Releases: `Sakht-File-Nasbi.bat` |
| `راهنمای دانلود.txt` | راهنمای گام‌به‌گام دانلود قطعه‌قطعه — در Releases: `Rahnamaye-Download.txt` |

### مراحل نصب
1. فایل `MehrStore-Setup.exe` را دانلود و اجرا کنید.
2. اگر ویندوز پیام آبی **SmartScreen** نشان داد: روی **More info** و سپس **Run anyway** کلیک کنید (این پیام به‌دلیل نداشتن امضای دیجیتال است و برنامه سالم است).
3. اگر مرورگر فایل exe را دانلود نکرد، فایل `MehrStore-Setup.zip` را بگیرید یا از نسخه ۵ بخشی استفاده کنید:
   - هر ۵ فایل `part` + فایل `ساخت فایل نصبی.bat` را در یک پوشه بگذارید و روی فایل bat دوبار کلیک کنید.
4. پس از نصب، برنامه به‌صورت خودکار اجرا می‌شود (آدرس `http://localhost:3000`).
5. ورود به سیستم: نام کاربری `admin` — رمز `admin123`

## ✨ امکانات

- 🧾 **صندوق فروش سریع** با جستجوی کالا، فروش وزنی (کیلوگرم/گرم) و پیش‌نمایش زنده مبلغ
- 📦 **مدیریت انبار** — کالا، دسته‌بندی، موجودی و قیمت خرید/فروش
- ⏰ **هشدار تاریخ انقضا** — نشان «منقضی» برای کالای تاریخ‌گذشته و شمارش روزهای باقی‌مانده
- 👥 **مدیریت مشتریان** — بدهی و اعتبار، دفتر حساب، پرداخت اقساطی
- 📊 **گزارش‌ها** — فروش روزانه/هفتگی/ماهانه، پرفروش‌ترین و پرسودترین کالاها، نمودار ساعت‌های شلوغ
- 💰 **هزینه‌ها و سود خالص** — ثبت هزینه‌ها بر اساس ۷ دسته و محاسبه سود واقعی
- 💾 **پشتیبان‌گیری خودکار روزانه** از دیتابیس + بکاپ دستی از تنظیمات
- 🧾 **چاپ رسید حرارتی ۸۰ میلی‌متری**
- 📨 **پیامک یادآوری بدهی** به مشتریان (سرویس کاوه‌نگار)
